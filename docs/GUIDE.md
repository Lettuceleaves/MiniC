# MiniC 使用指南

MiniC 是一个面向 C 语言子集教学的可视化工作台。它把源代码、编译流程、单步调试和数据结构视图放在同一个界面里，适合大一新生边写代码边观察程序如何被分析、执行和呈现。

## 快速开始

1. 在代码页输入或打开一个 MiniC 程序。
2. 使用编译器控制按钮依次观察源码、词法、语法、语义、中间表示、汇编和执行结果。
3. 切到调试页后，从头开始执行程序，可以用断点、本层步进和进入函数等粒度观察变量变化。
4. 如果程序里配置了数据结构可视化注释，右侧会根据运行时捕获到的数据渲染数组、链表、树、图、哈希表等视图。
5. 在设置页调整主题、快捷键、动画帧间隔、图形缩放灵敏度和全局界面缩放。

## 一个最小程序

```c
int main() {
    int a = 1;
    int b = 2;
    return a + b;
}
```

这段程序适合用来验证最基础的编译和运行流程：词法阶段会看到 `int`、`main`、`return` 等记号；语法阶段会把它组织成函数和语句；调试阶段可以逐行观察 `a`、`b` 的值如何进入当前栈帧。

## 数据结构可视化提示

数据结构视图关注的是“指针和内存关系”。例如链表不是只看某个变量的值，而是看每个节点的地址、节点里的字段，以及 `next` 指针把节点串起来的方向。树和哈希表也类似：MiniC 会优先保留教学上最容易读懂的主结构，再把共享节点、成环、命中、移动、旋转等运行时状态作为高亮信息补上。
