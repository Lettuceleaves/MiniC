# Web BS TypeScript Workbench Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a browser/server MiniC Visual Workbench that uses TypeScript on the web side, talks to a Java web adapter, and preserves the current JavaFX Workbench feature surface through `minic.uiapi`.

**Architecture:** The Java web adapter owns HTTP, WebSocket, session lifecycle, structured errors, and production asset serving. The adapter calls `minic.uiapi` only for compile/debug behavior; compiler, runtime, session, and `uiapi` packages never depend on `minic.web`. The TypeScript app consumes OpenAPI-generated types, renders Workbench parity screens, and treats REST snapshots plus WebSocket events as server state.

**Tech Stack:** Java 21, Gradle, Javalin 7.x, Jackson, JUnit 5, React, TypeScript, Vite 8.x, TanStack Router, TanStack Query, Zustand, Radix UI, Tailwind CSS, Monaco Editor, React Flow, Vitest, Testing Library, Playwright.

`MiniCWebServer` shape:

```java
package minic.web;

import io.javalin.Javalin;

import java.net.URI;
import java.util.Objects;

public final class MiniCWebServer implements AutoCloseable {
    private final Javalin app;
    private final String host;

    MiniCWebServer(Javalin app, String host) {
        this.app = Objects.requireNonNull(app, "app");
        this.host = Objects.requireNonNull(host, "host");
    }

    public static void main(String[] args) {
        MiniCWebApplication.create(MiniCWebConfig.development()).start();
    }

    public URI uri(String path) {
        String normalized = path.startsWith("/") ? path : "/" + path;
        return URI.create("http://" + host + ":" + port() + normalized);
    }

    public int port() {
        return app.port();
    }

    @Override
    public void close() {
        app.stop();
    }
}
```

```java
}
```

Core shape:

```ts
type JsonBody = Record<string, unknown> | undefined;

export class MiniCWebError extends Error {
  constructor(
    public readonly status: number,
    public readonly code: string,
    message: string,
  ) {
    super(message);
  }
}

async function request<T>(path: string, init: RequestInit & { json?: JsonBody } = {}): Promise<T> {
  const response = await fetch(path, {
    ...init,
    headers: { "Content-Type": "application/json", ...init.headers },
    body: init.json === undefined ? init.body : JSON.stringify(init.json),
  });
  const body = await response.json();
  if (!response.ok) {
    const error = body as { status: number; code: string; message: string };
    throw new MiniCWebError(response.status, error.code, error.message);
  }
  return body as T;
}
```
