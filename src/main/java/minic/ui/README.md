# UI source layout

The Java package remains `minic.ui` for compatibility. Files are grouped by UI responsibility:

- `app`: JavaFX application entry points.
- `workbench`: shell, controller, sidebar, playback, and shared UI state.
- `editor`: source editor, typing helpers, realtime analysis, and samples.
- `source`: source loading and source presentation views.
- `visual`: compiler pipeline visualization models and views.
- `debug`: debugger UI.
- `panel`: inspector, hover detail, and bottom panel models/views.
- `diagnostics`: diagnostics list and selection helpers.
