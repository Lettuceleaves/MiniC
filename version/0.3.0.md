# MiniC 0.3.0 阶段记录

发布日期：2026-05-03

## 阶段定位

`0.3.0` 是 MiniC 的 JavaFX UI 首版阶段。本阶段目标是基于 `0.2.0` 的 `minic.uiapi` 门面和不可变 DTO，实现 VS Code 风格的 MiniC Visual Workbench。

首版 UI 是编译全流程可视化工作台，不是完整 IDE，也不是运行时 debugger。

## 视觉风格

UI 风格参考本机原型：

```text
C:\Users\Administrator\Desktop\styleOfMiniC\index.html
```

已采用的方向：

- VS Code 风格深色工作台。
- titlebar、activity bar、sidebar、editor、visual pane、bottom panel、inspector、status bar 的分栏结构。
- 主背景 `#1e1e1e`，面板背景 `#252526`，顶栏背景 `#3c3c3c`，主强调色 `#007acc`。
- UI 字体优先 `Segoe UI`、`Microsoft YaHei`；源码和结构化输出使用 `Consolas`。

## 已完成能力

- JavaFX 构建接入：新增 `runUi` Gradle 任务，保留现有 CLI `run` 入口。
- UI 入口：`minic.ui.MiniCWorkbenchApp`。
- 启动修复：新增 `minic.ui.MiniCWorkbenchLauncher`，避免 Gradle `JavaExec` 直接启动 JavaFX `Application` 时触发缺少 JavaFX runtime 的 classpath 启动问题。
- UI 状态模型：`MiniCWorkbenchViewModel` 封装 `MiniCObservationApi`，只向 JavaFX 暴露 UI DTO 和 JavaFX property。
- 工作台外壳：实现 VS Code 风格 titlebar、activity bar、sidebar、editor、bottom panel、inspector、status bar。
- Sidebar：实现 workspace 区和 pipeline 阶段列表，展示 queued、running、done、error 和进度。
- Source View：实现带行号的源码视图，并根据当前源码范围或 diagnostic 范围高亮。
- Visual Pane：根据当前阶段显示 token、AST、semantic、IR、assembly 等摘要项。
- Bottom Panel：实现 Problems、Output、Terminal 风格底部面板。
- Inspector：实现右侧当前状态、当前项、累计输出和 Next/Play/2x/Pause 控制。
- Source Loader：支持选择内置样例、编辑源码并启动观测会话。
- Playback：通过 JavaFX Timeline 驱动播放 tick，逻辑层支持无真实等待测试。
- Diagnostics：实现 diagnostic 列表项、severity/code/message 展示和源码范围选择模型。

## 架构边界

- UI 层位于 `minic.ui`。
- UI 层只依赖 `minic.uiapi` 门面和 DTO，不直接访问 compiler、runtime stepper 或 session 内部对象。
- UI API 仍是 JavaFX 无关层。
- JavaFX 代码没有进入 compiler、runtime、session 或 uiapi 包。

## 仍未实现项

- 未实现真实进程调试、断点、变量观察、调用栈和运行时 debugger。
- 未实现反向步进、自动倒放或历史快照回退。
- Visual Pane 当前展示 DTO 摘要，不是完整 AST/IR 富对象图。
- Toolchain 阶段仍没有 stepper，UI 仅保留阶段槽位。
- 未做跨平台 UI 打包。
