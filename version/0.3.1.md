# MiniC 0.3.1 阶段记录

发布日期：2026-05-03

## 阶段定位

`0.3.1` 是 JavaFX Visual Workbench 的阶段专属图形化增强阶段。本阶段把 `0.3.0` 的摘要型 Visual Pane 升级为按编译阶段切换的图形视图。

## 已完成能力

- UI API 新增 `MiniCObservationApi.currentStageVisualData()`。
- 新增 `UiStageVisualDto` 聚合模型，以及 Lexer、AST、Semantic scope、Assembly 行 visual DTO。
- Lexer visual data 基于真实 token range，包含 token kind、text、start/end offset、1-based 起止行列和 active 标记。
- Lexer UI 以等宽源码行渲染 token overlay，保留空格、tab、换行，并对当前 token 使用半透明高亮。
- Parser visual data 将 AST 转换为 UI 专用树 DTO，保留 label、kind、children、source range 和 active 节点。
- Parser UI 以树形行展示 AST，并高亮当前 parser 节点。
- Semantic visual data 将作用域转换为 UI 专用树 DTO，根节点为 `global scope`，符号以摘要字符串展示，边方向语义为 child -> parent。
- Semantic UI 顶部显示 `global scope`，子作用域向下展开，用向上箭头表达反向边，并强调当前路径。
- Codegen visual data 使用完整汇编行快照，提供稳定行号、文本、kind、section、label 和 active 当前行。
- Assembly UI 使用 `Consolas` 等宽文本行，按 codegen step 增量追加并高亮当前行。
- Visual Pane 根据 `visualType` 自动切换 Lexer、AST、Semantic、Assembly 或 generic fallback，`next`、`play`、`playFast`、`tick` 都会刷新 visual DTO。

## 架构边界

- JavaFX UI 仍位于 `minic.ui`。
- UI API 位于 `minic.uiapi`，返回不可变 UI DTO。
- UI 层只依赖 `minic.uiapi` 门面和 DTO，不直接访问 compiler、runtime stepper 或 session 内部对象。
- AST、Scope、Symbol、IR、Stepper、Emitter 和 FrameLayout 等内部对象不向 UI API 使用者暴露。
- Semantic 层 `Scope` 增加只读 symbols/children 快照能力，用于构建 UI 专用 DTO。

- Semantic 当前作用域 active 关联仍是摘要级映射，后续可进一步把语义动作与具体作用域建立更精确关系。
- 未做跨平台 UI 打包。
