# MiniC 0.4.0 阶段记录

发布日期：2026-05-06

## 阶段定位

`0.4.0` 是 C 子集语法和预编译扩展阶段。本阶段在正式 lexer/parser 前加入轻量预编译器，并补充常用表达式、可变参数外部函数声明、`do while` 和 `switch case default`。

## 已完成能力

- 预编译 pipeline：`preprocess -> lexer -> parser`。
- `.mh` include：支持相邻路径和显式 include 根目录、嵌套 include、循环检测、`.mh` 后缀限制和 include 摘要。
- 对象宏：支持 `#define NAME value`、`#define NAME`、`#undef NAME`，普通源码替换不进入字符串/字符字面量。
- 条件编译：支持 `#ifdef/#ifndef/#else/#endif`，排除分支不进入输出源码。
- MiniC 头文件校验：`.mh` 允许函数声明、外部函数声明、结构体声明、宏和条件编译，拒绝函数定义和可执行语句。
- 可变参数声明：支持 `extern int printf(char *format, ...);`，固定参数继续做语义检查，额外参数允许传入。
- 表达式扩展：复合赋值、取余、位运算、逻辑运算、移位、`?:`、`sizeof`、自增自减相关 token/解析/语义/IR/codegen；`&&`、`||` 和 `?:` 使用控制流 lowering 保留短路副作用。
- 控制流扩展：支持 `do while` 和 `switch case default` 的 parser、semantic、IR lowering 和 Windows x64 codegen。
- 新增样例：`samples/minic_std.mh`、`samples/phase_d.mc`，并更新 `samples/printf.mc` 使用头文件中的标准方向 `printf` 原型。

## 已知限制

- 预处理器仍为轻量实现，不支持函数式宏、`#if/#elif` 表达式、系统 include 路径或 `.h` 文件。
- `case` 常量表达式当前支持字面量级整数常量，未实现完整常量折叠。
