# MiniC 0.5.0 阶段记录

`0.5.0` 完成教学型可视化 Debugger 首版。

## 已完成能力

- Debugger 作为 Workbench 独立模式接入，不进入普通编译观察流水线。
- IR Interpreter 支持 main 执行、表达式、控制流、内部函数调用、调用栈和外部 `printf` debug stub。
- DebugSession 支持断点、运行到断点、快进、暂停请求、重启、关闭、单退、步退和返回调用处。
- 运行时状态按虚拟进程空间呈现：code、static/data、stack、heap、io。
- Source/AST/IR/ASM DebugMappingIndex 已建立，ASM 视图是生成汇编映射展示，不代表真实 CPU 状态。
- UI API 暴露独立 Debug DTO，不向 UI 泄漏 runtime debug 内部对象。
- Workbench Debug activity 已接入，包含元数据、数据结构、AST、IR、ASM tabs 和右侧拆分对比。
- 数据结构图形化基础设施已建立：GraphStructure、ArrayStructure、CompositeStructure。
- `@visual`、`@visual-node`、`@visual-edge` 注释协议已解析，第一版 root 只接受变量名，node/edge 只接受简单变量名或字面值。
- 首批 DataStructureDescriptor 已提供：array、matrix、list、doubly_linked_list、tree、binary_tree、bst、heap、graph、hash_table、union_find；红黑树未纳入首批。

## 样例

- `samples/debugger_basic.mc`：基础 Debug、函数调用和 `printf` stub。
- `samples/debugger_array_matrix.mc`：数组和矩阵 visual 注释。
- `samples/debugger_graph.mc`：链式图和 `@visual-node/@visual-edge`。
- `samples/debugger_composite.mc`：bucket array + graph 的混合结构注释。

## 已知限制

- Debugger 执行 IR Interpreter，不调试真实 exe，不接 Windows Debug API。
- 外部调用副作用不纳入反向恢复承诺；首版仅通过 debug stub 记录可控输出。
- Workbench 首版 Debug 断点控制已接入，但 RichTextFX gutter 点击断点和当前执行行视觉强化仍需后续 UI 细化。
- 数据结构投影首版以 root 和注释驱动为主，复杂指针/数组/结构体运行时深度扫描可在后续版本扩展。
